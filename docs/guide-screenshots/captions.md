# AI-TMS 사용법 가이드 — 스크린샷 캡션

> **번호 안내**: 요청하신 원래 01~18번 순서 중 두 항목(④ 수기작성 TC 생성, ⑱ 결함 등록)은 실제로는 서로 다른 화면 상태를 각각 보여줘야 해서 2장씩으로 나눴습니다. 그래서 전체가 20장이 되며, 그 뒤 번호가 하나씩 밀렸습니다. AI 관련 기능은 `[AI 기능]`로 표시했습니다.

01-login.png: 로그인 화면. 아이디/비밀번호 입력 후 '로그인' 버튼을 누르면 됩니다.

02-dashboard.png: 로그인 직후 보이는 대시보드. 현재 선택된 프로젝트의 총 테스트케이스·수행 통과율·열린 이슈·활성 테스트 차수 요약과 최근 이슈, 차수별 진행률을 한눈에 확인합니다.

03-common-project.png: 헤더 우측 프로젝트 선택기에서 '공통 테스트케이스'로 전환한 화면(좌측 폴더트리 + 우측 TC 목록). 공통 테스트케이스는 은행 공통 검증항목을 모아둔 참고용 프로젝트입니다. 여기서 '가져오기'로 복사해가면 그 이후로는 독립된 사본이라, 공통 원본을 나중에 수정해도 이미 가져간 프로젝트의 사본에는 영향이 없습니다.

04-manual-create.png: 테스트케이스 생성방법 (1) 수기작성 — '+ 테스트케이스 추가' 팝업. 테스트 단계/기대결과에 `{amount}`, `{expected}` 같은 변수를 입력하고 '파라미터화' 토글을 켠 상태입니다. 저장하면 데이터셋 탭으로 바로 이동합니다.

05-manual-dataset.png: 저장 직후 이동한 데이터셋 탭에서 `amount` 열에 최소값(10,000)·최대값(3,000,000) 등 값을 여러 세트(행)로 입력하는 모습. 한 TC로 여러 조건을 반복 실행할 수 있습니다.

06-excel-upload.png: 테스트케이스 생성방법 (2) 엑셀 업로드 — '엑셀 업로드' 팝업이 열린 상태. 정해진 양식(제목·스텝·기대결과·폴더경로·기법)의 .xlsx 파일을 끌어다 놓거나 선택하면 한꺼번에 검토대기(DRAFT) TC로 등록됩니다. 먼저 '템플릿 다운로드'로 양식을 받아 채우면 됩니다.

07-ai-recommend-running.png: `[AI 기능]` 테스트케이스 생성방법 (3) AI 추천 — 요구사항 탭에서 요구사항 원문을 입력·등록한 뒤 '✨ AI 추천 요청' 버튼을 누른 직후 상태로, 제목 옆과 목록 행에 '✨ AI 추천 중…' 뱃지가 떠 있습니다. 완료되면 뱃지가 사라지고 결과가 표시됩니다.

08-review-inbox-select.png: `[AI 기능]` AI 생성 검수 화면(테스트케이스 탭의 'AI 생성 검수'). AI 추천/엑셀 업로드로 만들어진 검토대기(DRAFT) TC 중 2건을 체크한 상태로, 상단 '✓ 일괄 승인' / '✕ 일괄 반려' 버튼을 누르기 직전입니다. 개별 행을 클릭하면 TC 상세에서 1건씩 승인/반려할 수도 있습니다.

09-new-project-form.png: 헤더 우측 프로젝트 선택기 → '새 프로젝트 만들기'로 연 등록 폼. 코드·프로젝트명·설명을 입력한 상태입니다. '등록'을 누르면 바로 이 프로젝트로 전환되고, 등록한 사람이 PM으로 자동 참여합니다.

10-new-project-empty.png: 새 프로젝트 생성 완료 후 자동으로 전환된 직후의 빈 테스트케이스 화면(폴더·TC 0건). 여기서부터 실제 업무를 시작합니다.

11-import-search.png: '다른 프로젝트에서 가져오기' 팝업에서 '공통'으로 검색한 결과 — 공통 테스트케이스 프로젝트의 승인된 TC들이 모두 조회됩니다. 필요한 항목에 체크한 뒤 '가져오기'를 누르면 됩니다.

12-import-done.png: 가져오기 실행 직후, 새 프로젝트 TC 목록에 선택했던 TC들(금액 템플릿 1건 + 일반 TC 2건)이 새 사본으로 복사되어 들어온 상태.

13-imported-dataset-edit.png: 가져온 '금액 필드 경계값 표준 검증' TC 상세의 데이터셋 탭. 템플릿의 예시 값(100,000)을 우리 프로젝트의 실제 조건(5,000,000)에 맞게 수정하는 중입니다 — 이렇게 값만 바꿔서 바로 재사용할 수 있는 게 포인트입니다.

14-new-cycle-form.png: 테스트수행 화면의 '+ 새 차수' 폼에 차수명을 입력한 상태. '생성'을 누르면 차수 상세로 이동합니다.

15-cycle-tc-added.png: 차수 상세에서 'TC 추가' 피커 모달로 앞서 만든/가져온 TC들을 전체 선택해 담은 직후의 목록 화면. 파라미터화 TC는 데이터 행마다 실행 항목이 개별로 생깁니다.

16-execution-autosave.png: TC 실행 패널에서 결과를 '성공'으로 선택하고 코멘트를 입력한 뒤, 저장 버튼 없이 자동으로 저장되어 우측 상단에 '✓ 저장됨'이 표시된 상태.

17-excel-download-menu.png: 차수 상세의 '엑셀 다운로드' 버튼을 누른 직후 — '이 차수만 다운로드' / '전체 차수 다운로드' 드롭다운이 열립니다. 클릭하면 새 탭에서 바로 .xlsx 파일이 내려받아집니다.

18-fail-result-defect-link.png: 다른 TC를 '실패'로 처리한 직후 상태. 결과가 FAIL이면 붉은 첨부 유도 문구와 함께 '연결된 이슈' 영역에 '+ 이슈 등록' 버튼이 자동으로 나타납니다(실패→결함등록 연동 기능이 실제로 있습니다 — 자세한 내용은 채팅 답변 참고).

19-defect-form-prefilled.png: '+ 이슈 등록' 버튼을 눌러 들어간 결함 등록 폼. 상단에 '연결된 테스트 수행'(TC 코드·제목·결과)이 자동으로 표시되고, 제목과 상세 내용(재현 절차/기대 결과/실제 결과 템플릿)도 실패 정보 기반으로 자동 채워져 있습니다. 필요한 내용을 보완하고 '저장'하면 됩니다.

20-defect-detail.png: 결함 등록 완료 후 이동한 상세 화면. 코드(DF-0001)가 채번되고, 연결된 TC·차수 정보와 상태 변경(열림/반려) 버튼이 보입니다.
