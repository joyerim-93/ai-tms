# ai-tms 디자인 v3 (상단 탭 네비 + 화이트 톤)

기존에 논의했던 "좌측 사이드바 + 다크모드" 방향을 폐기하고,
공유해주신 스크린샷 스타일로 갈아엎습니다. 지금은 **라이트 모드만** 구현하고,
CSS 변수로 토큰화해서 다크모드는 나중에 값만 추가하면 되게 설계합니다.

## 1. 레이아웃 구조

```
┌───────────────────────────────────────────────────────────┐
│ AI-TMS   대시보드  테스트케이스  테스트 수행  이슈관리        │ ← 상단 헤더 (고정)
├───────────────────────────────────────────────────────────┤
│ [✓ AI-TMS 2단계] [오픈뱅킹 리뉴얼] [내부 결재 시스템]         │ ← 프로젝트 탭(pill selector)
├───────────────────────────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐        │
│ │총 테스트  │ │수행 통과율│ │열린 이슈  │ │활성 테스트│        │ ← 요약 카드 4개
│ │케이스     │ │           │ │           │ │차수        │        │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘        │
│ ┌────────────────────────┐ ┌────────────────────────┐      │
│ │ 최근 등록된 이슈          │ │ 테스트 차수별 진행률       │      │
│ │ (리스트, 뱃지 상태)       │ │ (프로그레스바 + 요약)     │      │
│ └────────────────────────┘ └────────────────────────┘      │
└───────────────────────────────────────────────────────────┘
```

- 좌측 사이드바 **없음**. 상단 헤더에 로고 + 메뉴 탭 (대시보드/테스트케이스/테스트 수행/이슈관리 = 우리 4대 기능)
- 헤더 바로 아래에 **프로젝트 선택 탭**(pill 버튼) — 여러 프로젝트를 전환하는 용도. 선택된 프로젝트는 좌측에 체크 아이콘 + 강조색
- 요약 카드 4개는 대시보드 전용, 다른 화면(테스트케이스/테스트수행/이슈관리)에서도 화면 상단에 관련 요약 카드를 재사용

## 3. 컴포넌트 목록 (Vue 컴포넌트로 분리)

| 컴포넌트 | 설명 |
|---|---|
| `AppHeader.vue` | 로고 "AI-TMS" + 4개 메뉴 탭, 현재 라우트에 따라 활성 탭 하이라이트 |
| `ProjectTabs.vue` | 프로젝트 전환용 pill 탭, 선택된 것에 체크 아이콘 |
| `StatCard.vue` | 요약 카드 1개 (제목, 큰 숫자, 보조텍스트 — "+32 이번 주" 같은 증감 표시) |
| `IssueListCard.vue` | 최근 이슈 리스트 (뱃지 상태 포함), "전체보기" 링크 |
| `TestRoundProgressCard.vue` | 차수별 진행률 (프로그레스바 + 통과/실패/보류/미실행 요약 텍스트) |
| `StatusBadge.vue` | 공용 뱃지 컴포넌트, `status` prop으로 색상 매핑 (열림/진행중/해결됨/종료, 성공/실패/block/미수행 등 재사용) |

## 레이아웃 변경
- 기존에 논의했던 좌측 사이드바 구조는 폐기하고, 상단 헤더 + 탭 메뉴 구조로 바꿔줘.
- 헤더: 좌측 "AI-TMS" 로고, 우측으로 "대시보드 / 테스트케이스 / 테스트 수행 / 이슈관리" 4개 탭 메뉴.
  현재 라우트에 해당하는 탭에 강조색(--accent) 밑줄 표시.
- 헤더 아래에 프로젝트 선택 pill 탭 컴포넌트(ProjectTabs.vue) 배치. 지금은 더미 프로젝트 2~3개로 구현.
- 대시보드 화면 구성:
  1. 요약 카드 4개 가로 배열 (총 테스트케이스 / 수행 통과율 / 열린 이슈 / 활성 테스트 차수)
     각 카드는 제목(회색, 작게) + 큰 숫자 + 보조텍스트(증감 표시, 예: "+32 이번 주")
  2. 하단 2단 배치: 좌측 "최근 등록된 이슈" 리스트 카드, 우측 "테스트 차수별 진행률" 카드
     - 이슈 리스트: 이슈번호, 제목, 담당자+시간, 상태 뱃지(열림/진행중/해결됨/종료)
     - 진행률 카드: 차수명 + 진행률% + 프로그레스바 + "전체 N · 통과 N · 실패 N · 보류 N · 미실행 N" 요약
